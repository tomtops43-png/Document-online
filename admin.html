จัดการเอกสารที่ลงทะเบียนไว้ (แก้ผิด / เลิกใช้แล้ว)

กด "ลบ" แล้วเอกสารจะหายจากทุกหน้าทันที (Document Center, ค้นหา, ผูก Station ฯลฯ) แต่ข้อมูลเดิมยังอยู่ในชีท ENC-MASTER — กู้คืนได้เองโดยเปิดชีท M_Document แล้วแก้ค่า status ของแถวนั้นกลับเป็น ACTIVE

เอกสารไลน์ประเภทซีรีส์กลุ่มรุ่นเลขที่เอกสารRevision ปัจจุบัน

แก้ไขข้อมูลเอกสาร

แก้ได้เฉพาะข้อมูลของเอกสาร — ถ้าต้องการเปลี่ยนไฟล์/เนื้อหา ใช้แท็บ "เพิ่ม Revision" แยกต่างหาก

📋 เอกสารประเภทฟอร์ม (First Piece / Check Sheet จาก Excel)

  1. อัปโหลดไฟล์ Excel Master ขึ้น Google Drive ของคุณ
  2. แชร์ให้ "ทุกคนที่มีลิงก์ดูได้" แล้ว copy ลิงก์
  3. ส่งลิงก์ให้ Claude ในแชท พร้อมบอก ไลน์ / Station / รุ่น
  4. Claude จะอ่านไฟล์ แกะโครงสร้างรายการตรวจ แปลงเป็น template JSON แล้ว push เข้าระบบ + ลงทะเบียนให้อัตโนมัติ (มีหลักฐานใน Git ทุก revision)
